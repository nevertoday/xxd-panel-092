# XXD Panel 092 オリジナルプロンプト · 日本語読解訳

アップロードした写真をそれぞれ、独立した一枚の上質なデザインポスターにしてください。複数画像を組み合わせず、各写真を個別に出力します。全体は3:4の縦構図とし、上下2領域の高さを厳密に1:1、各領域を画面の50%にしてください。

上半分には元の写真を残し、主体の同一性、構造、ポーズ、リアルな質感、自然な光と影、元の色彩の雰囲気を保ってください。施すのはわずかな上質のカラーグレーディングだけとし、アート雑誌、インディペンデント出版物、展覧会写真のような質感を与えます。画面比率に合わせて周囲の背景を自然に拡張しても構いませんが、主体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別性の高い**主体、輪郭、構造、ポーズ、物語上の関係**を抽出し、表現的なペン線画へ再構成してください。写真全体をそのままなぞったり、写実的なイラストへ変換したりしてはいけません。最も重要な同一性の特徴と場面の論理だけを残し、元の対象が一目で分かると同時に、要約・削減・再編成による造形美が明確に感じられるようにします。

画面の核は**輪郭線描 + 排線による造形**です。主体の形は主に、ゆるやかでありながら正確な contour line drawing で築き、暗部と構造の転換は diagonal hatching、cross-hatching、scribble hatching によって明暗の階調を作ります。線は整いすぎている必要はありません。素早く自由で、少し走り書きのような身振りのある筆致、わずかな重ね描きによる修正、完全には均一でない密度変化を残し、観察感、速度感、手仕事の気配を同時に備えた画面にしてください。

構図では**negative-space composition**を重視します。大きな負形、密な排線が作る暗い量塊、余白との対比を利用し、明確な主従関係と強いグラフィック性を築いてください。主体は必ずしも中央に置く必要はなく、元画像で最も力のある視覚的関係に応じて位置を再編成できます。複雑な背景は積極的に削ぎ落とし、必要最小限の環境構造、卓上、地面、境界、空間の手掛かりだけを残して、余白、白黒の密度、排線のリズムがともに画面の呼吸を形作るようにします。

全体には、好みである**自由な輪郭線 × 幾何学的な排線**の関係を保ってください。人物、動物、植物、器物、建築の輪郭は、ゆるく柔軟で曲線的にして構いません。一方、卓上、壁面、地面、家具、構造の境界、影の方向、環境の秩序は、まとまりのある斜線、交差排線、線形の幾何学的関係によって安定したレイアウトの骨格を築き、ゆるさと秩序の間に緊張感を保ちます。

下半分は黒、グレー、紙の白を中心とし、低彩度の補助色をごく少量残しても構いませんが、全体の核はあくまでペン線画の言語です。背景には生成りまたは淡い暖白色の紙面を使い、大きな余白を設け、濁ったグレー、過剰な描き込み、複雑なテクスチャを避けてください。重点は色面の展開ではなく、線の密度、白黒の関係、負形、レイアウトのリズムにあります。

文字は少量だけ介入させ、写真の内容に応じて短いタイトル、語句、または小さな注釈を自由に抽出します。言語は限定しません。文字は小さく、軽く、抑制的にし、editorial illustration と sketchbook aesthetic の組版らしさを持たせます。余白、境界、線形構造に沿って自然に配置し、固定されたタイトルバーやメニュー式の情報ではなく、静かで洗練された図文関係を作ってください。

全体のスタイルは **pen and ink illustration, loose contour lines, expressive linework, diagonal hatching, scribble hatching, cross-hatching, minimal black-and-white drawing, negative space, editorial illustration, sketchbook aesthetic** を参照し、上質で現代的、抑制的、芸術的な視覚効果を表現してください。写実的なイラスト、太い黒の漫画線、整然としたベクター線、カートゥーン調、過剰な細部、コンピューターフィルター感、テンプレート化されたポスター感は避けてください。
