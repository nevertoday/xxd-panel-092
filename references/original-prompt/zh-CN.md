# XXD Panel 092 原始提示词 · 简体中文原文

请将我上传的每一张照片分别制作成一张独立的高级设计海报，不多图拼接，每张照片单独输出。整体采用3:4竖版构图，上下两个区域高度严格1:1，各占画面50%。

上半部分保留原始照片，保持主体身份、结构、姿态、真实质感、自然光影和原有色彩氛围，仅进行轻微高级调色，使其具有艺术杂志、独立出版物与展览图像质感。为适配画幅，可自然扩展环境背景，但不得拉伸、扭曲或改变主体。

下半部分提取照片中最具识别性的**主体、轮廓、结构、姿态与叙事关系**，重构为表现性钢笔线描插画。不要完整描摹照片，也不要转成写实插画，只保留最关键的身份特征与场景逻辑，让人一眼认出原物，同时明显感受到概括、删减与重新组织后的图形美感。

画面以 **轮廓线描 + 排线塑造** 为核心：主体主要通过松散而准确的 contour line drawing 建立形体，暗部与结构转折通过 diagonal hatching、cross-hatching 和 scribble hatching 形成明暗层次。线条不必过于规整，应保留快速、自由、略带潦草的手势性笔触、轻微重复修正与不完全均匀的密度变化，使画面同时具有观察感、速度感与手工气息。

构图强调 **negative-space composition**。可利用大面积负形、密集排线形成的深色量块，以及留白之间的对比，建立清晰的主次关系与强烈的图形感。主体不一定完全居中，可根据原图最有力量的视觉关系重新组织位置；复杂背景主动删减，只保留少量必要环境结构、桌面、地面、边界或空间线索，让留白、黑白密度和排线节奏共同构成画面的呼吸感。

整体保留你喜欢的**自由轮廓线 × 几何排线**的关系：人物、动物、植物、器物或建筑轮廓可以松散、灵活、带曲线感；桌面、墙面、地面、家具、结构边界、阴影方向或环境秩序则通过成组斜线、交叉排线和线性几何关系建立稳定的版式骨架，使画面在松弛与秩序之间保持张力。

下半部分以黑、灰、纸白为主，可保留极少量低饱和辅助色，但整体仍应以钢笔线描语言为核心。背景使用米白或浅暖白纸面，大面积留白，避免灰脏、过度渲染与复杂纹理。重点不是颜色铺陈，而是线条密度、黑白关系、负形和版式节奏。

文字少量介入，根据照片内容自由提炼简短标题、词句或微型注释，不限制语种。文字应小、轻、克制，具有 editorial illustration 与 sketchbook aesthetic 的排版气质，可沿留白、边界或线性结构自然分布，与画面形成安静、精致的图文关系，而不是固定标题栏或菜单式信息。

整体风格参考 **pen and ink illustration, loose contour lines, expressive linework, diagonal hatching, scribble hatching, cross-hatching, minimal black-and-white drawing, negative space, editorial illustration, sketchbook aesthetic**，呈现高级、现代、克制、艺术化的视觉效果。避免写实插画、粗黑漫画线、整洁矢量线、卡通感、过度细节、电脑滤镜感和模板化海报感。
